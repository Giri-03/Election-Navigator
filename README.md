# Election-Navigator

## Problem
Understanding the election process is confusing for many users.

## Solution
An AI-powered assistant that guides users step-by-step through eligibility, timelines, and voting actions.

## Features
- Eligibility Checker
- Personalized Timeline
- Step-by-step Checklist
- Interactive Assistant Flow

## Tech Stack
Flask, Gunicorn, Render, Prompt Engineering

## Live Demo
https://election-navigator.onrender.com/

## How it Works
User inputs → System processes → Returns structured guidance
